# PACE — 경력직 이직 페이스메이커

퇴근 후 15분, 내 경력기술서와 지원 회사의 JD(채용공고)만으로 실무 팀장급 압박 면접을 시뮬레이션하는 단일 파일 웹앱입니다.

**Live:** https://jyk3220-hash.github.io/career-pacemaker/

## 모드

1. **적합도 · 교차 검증** — JD 요구를 분해해 경력기술서의 근거와 대조하고, Fit/Gap·예상 질문·면접관 반박 포인트·수정 스크립트를 만듭니다. 지원 직무의 KPI 커버리지도 함께 보여줍니다.
2. **성과 진위 3단 꼬리질문** — ① 본인 기여 vs 팀·에이전시 ② 실패한 가설과 수정 데이터 ③ 비즈니스 임팩트·재현 가능성. 축별 점수와 최종 리포트를 제공합니다.
3. **민감 질문 방어** — 잦은 이직, 짧은 근속, 퇴사 사유, 희망 연봉, 공백기를 비즈니스 언어 스크립트와 예상 꼬리질문으로 교정합니다.
4. **출퇴근길 5분 통화 면접** — 전화 통화 UI로 질문을 듣고 말로 답합니다. 말이 끝난 뒤 약 1.8초의 침묵을 감지해 자동으로 다음 질문으로 넘어가고(3문항), 통화가 끝나면 코치 목소리의 3단 오디오 브리핑(전반적 인상 → 가장 아쉬웠던 답변과 수정안 → 다음 연습 포인트)을 재생합니다. 음성 인식이 없거나 권한이 없으면 텍스트로 답할 수 있습니다.
5. **면접장 직전 치트시트** — 완료한 세션(적합도·3단 꼬리질문·민감질문·5분 통화)이 회사·직무 태그, 핵심 수치, 합격 스크립트, 방어 논리를 담은 카드로 자동 정리됩니다. 터치 스와이프·화살표로 넘기고, 필터와 고정(pin)을 쓸 수 있으며 `localStorage`에 저장됩니다.

## 직무 KPI DB

그로스·퍼포먼스 마케터, PM/PO, 백엔드·데이터, B2B 세일즈·BD, 화학·배터리 공정 R&D, 재무·전략, HR·조직의 핵심 KPI와 단골 압박 질문을 내장했습니다. JD에서 직무를 자동 감지하거나 직접 고를 수 있고, 선택한 직무의 KPI·압박 패턴이 적합도 분석, 5분 통화 질문, OpenAI/Gemini/Claude 프롬프트에 함께 반영됩니다.

## 엔진

- **내장 엔진(기본)** — API 키 없이 동작합니다. 입력에서 수치·도메인 키워드·요구 역량을 실제로 추출해 질문을 만들기 때문에 고정 데모가 아닙니다.
- **OpenAI / Gemini / Claude** — 설정에서 키를 넣으면 `gpt-4o-mini`·`gpt-4o`, `gemini-2.5-flash`·`gemini-2.5-pro`, 또는 Claude(`claude-sonnet-4-6`·`claude-sonnet-5-5`·`claude-haiku-5-5`·`claude-opus-5-5`)로 실시간 면접 질문을 생성합니다. Claude는 Anthropic Messages API를 브라우저에서 직접 호출합니다(`anthropic-dangerous-direct-browser-access` 헤더 사용). 키는 브라우저 `localStorage`에만 저장되며 서버로 전송되지 않습니다.

## 실행

`index.html` 하나로 동작합니다. 로컬에서 열거나 정적 호스팅(GitHub Pages 등)에 올리면 됩니다.

PDF 경력기술서는 `pdf.js`(CDN)로 브라우저에서 텍스트를 추출합니다. 스캔 이미지 PDF는 텍스트를 붙여넣어야 합니다.

## 참고

- 연습 도구이며 실제 채용 결과를 보장하지 않습니다.
- 입력·세션 기록은 브라우저 저장소에만 남습니다. API 키를 사용할 때만 해당 사업자로 면접 텍스트가 전송됩니다.
- 무료 체험(분석 3회)은 UI 안내용이며, 내장 엔진은 횟수와 무관하게 계속 사용할 수 있습니다.
